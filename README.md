# Limpeza e Padronização de Planilhas com Python

## Sobre o projeto

Este projeto tem como objetivo automatizar a limpeza, a padronização e a organização de dados armazenados em planilhas do Google Sheets, utilizando Python e Pandas.

A iniciativa surgiu de uma necessidade real no ambiente de trabalho: melhorar a qualidade e a organização de dados de inventário de equipamentos audiovisuais, facilitando sua utilização em análises e dashboards.

O fluxo proposto conecta a leitura dos dados, seu tratamento automatizado e a disponibilização dos resultados no Google Sheets, permitindo sua posterior utilização no Looker Studio.

## Objetivos

- Automatizar tarefas repetitivas de limpeza de dados.
- Padronizar textos e valores inconsistentes.
- Corrigir inconsistências identificadas durante o tratamento.
- Organizar a estrutura das tabelas para facilitar análises.
- Exportar os dados tratados para o Google Sheets.
- Preparar os dados para a construção de dashboards no Looker Studio.

## Tecnologias

- **Python:** desenvolvimento da automação.
- **Pandas:** manipulação, transformação e tratamento dos dados.
- **Google Sheets:** fonte dos dados e destino dos dados tratados.
- **Looker Studio:** ferramenta de visualização e construção de dashboards.

## Fluxo de trabalho planejado

1. Conectar-se às planilhas do Google Sheets e ler os dados.
2. Analisar a estrutura e identificar inconsistências.
3. Padronizar textos e valores.
4. Corrigir inconsistências e organizar colunas e tabelas.
5. Exportar os dados tratados para o Google Sheets.
6. Disponibilizar os dados para utilização no Looker Studio.

## Aplicação prática

O projeto utiliza como referência uma necessidade real relacionada à organização e à análise de dados de inventário de equipamentos audiovisuais.

Por motivos de confidencialidade, dados internos, números de série, valores comerciais e outras informações sensíveis não serão publicados sem autorização. Exemplos públicos deverão utilizar dados fictícios ou devidamente autorizados.
